# V3.2.7 — Telegram /trade command

Adds a forensic trade-history command without changing entry, exit, sizing,
sleep-mode, anti-whipsaw, or risk logic.

## Commands
- `/trade` — latest 15 closed trades with actual OKX average entry/exit prices,
  open/close times, hold duration, post-fee PnL, setup/trigger when available,
  and bot exit reason when the trade was tracked by the lifecycle journal.
- `/trades` — alias of `/trade`.

`/trade` is intentionally independent of `/restats`; resetting the statistics
cursor does not hide the latest account trades.

OKX `account/positions-history` is authoritative for entry/exit/PnL. Local
journal metadata only enriches the OKX row and never overrides OKX prices/PnL.
