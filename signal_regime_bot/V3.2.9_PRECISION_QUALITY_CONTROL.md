# V3.2.9 Precision Quality Control

Goal: improve entry quality after the recent 15-trade sample showed 40% WR and
profits concentrated in two large winners. This release does **not** add more
entry types. It makes the existing expert modes reject poor locations that a
high Regime/Bias score previously could compensate for.

## Hard location / chase gate
- Blocks a first entry (not only re-entry) after an already extended 5M impulse.
- Default late-entry conditions: 3-bar favorable move >= 1.10 ATR together with
  distance from EMA20 >= 0.60 ATR, or absolute EMA20 extension >= 0.90 ATR.
- BREAKOUT_RETEST is exempt because the retest is explicit acceptance of a new
  level.
- BTC/ETH have a tighter ordinary-entry extension ceiling of 0.72 ATR.

## SMC FVG / Order Block quality
- FVG/OB is treated as **location**, not an entry trigger by itself.
- A zone touch now needs 5M micro-structure confirmation (micro break or BOS).
- SMC EMA20 extension was tightened from 3.40 ATR to 1.10 ATR globally.
- BTC/ETH SMC additionally require 15M structure alignment/BOS and <=0.72 ATR
  extension.
- Trend SMC room requirement is 1.25R.

## Liquidity Sweep quality
- A wick sweep must also produce micro-structure confirmation (micro break/BOS).
- BTC/ETH 5M sweeps require supportive 15M structure and <=0.72 ATR extension.
- Trend sweep room requirement is 1.20R.

## HTF room gate
- Opposing active SMC zones remain hard barriers.
- Confirmed 1H/4H support/resistance is now also included in the hard room gate.
- 15M minor pivots are intentionally excluded to avoid returning to the old
  over-filtered behavior.
- General minimum room increased modestly from 1.05R to 1.15R.
- Breakout-retest keeps a lower 1.00R floor because it is explicitly breaking a
  prior barrier.

## BTC / ETH correlation guard
- The bot will not open BTC and ETH in the **same direction** at the same time.
- This prevents using both portfolio slots for essentially the same crypto-beta
  thesis.

## Setup x Symbol probation
- Uses the V3.2.8 persistent close journal only after >=8 samples exist for the
  same symbol + setup.
- If historical PF <0.90 or WR <35%, the setup is not permanently disabled.
  It must simply clear a larger current score edge (default +6) to trade.
- Old rows without setup metadata do not affect this guard.

## Unchanged
- Fixed margin default: 20 USDT
- Leverage: 20x
- AI Exit Engine
- V3.2.5 anti-whipsaw post-exit reset
- FX Sleep Mode
- Persistent position recovery / OKX SL-TP sync
- /trade persistent journal
- Existing TP/SL geometry and fee-aware execution

This release targets false entries and late entries. It does not claim or
promise a specific win rate; forward results should be evaluated by setup and
symbol with the V3.2.8+ journal.
