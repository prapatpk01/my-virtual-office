# V3.2.2 BTC Position Sync Fix

Fixes startup reconciliation failing to adopt a real OKX BTC position even though
its TP/SL are visible in the OKX app.

Root causes fixed:
- OKX one-way mode returns `posSide=net`; the prior parser rejected it while
  looking for a normalized `short` or `long` side.
- The CCXT implicit method name for `orders-algo-pending` differs by version.
  The bot now resolves all known method names dynamically.
- Added `trigger` algo-order lookup and additional normalized TP/SL field names.

The bot remains read-only during reconciliation. It never replaces live OKX
protection and never invents a fallback stop.
