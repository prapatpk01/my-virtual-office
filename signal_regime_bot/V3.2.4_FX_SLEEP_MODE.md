# V3.2.4 — Global FX Sleep Mode

## Policy
- Applies to **every configured symbol**: BTC, ETH, SOL, XRP, HYPE, XAU, XAG, etc.
- Standard FX weekly reference: Sunday 17:00 → Friday 17:00 `America/New_York`.
- New entries stop at Friday 17:00 New York.
- New entries resume **Sunday 13:00 New York**, exactly 4 hours before the regular Sunday 17:00 FX open.
- Time calculation is DST-safe through `zoneinfo` + `tzdata`.
- Existing positions continue normal management while Sleep Mode is ON:
  - OKX native SL/TP remains live
  - TP1 / BE logic continues
  - AI Exit Engine continues
  - reconciliation / recovery continues
- Flat symbols are not candle-polled during Sleep Mode, reducing weekend API traffic.
- A second hard gate is placed immediately before opening any new order so a boundary-time race cannot create a position during Sleep Mode.

## Visibility
Railway logs show a transition once when Sleep Mode turns ON/OFF and the periodic status banner shows the mode and resume time.
Telegram startup message includes the current Sleep Mode state. Telegram sends one message on future ON/OFF transitions.

## Legacy metals gate
The old XAU/XAG-only weekend gate is disabled because the global all-symbol FX Sleep Mode supersedes it.
