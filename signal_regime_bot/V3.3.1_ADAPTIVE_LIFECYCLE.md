# V3.3.1 Adaptive Lifecycle

Built from the user's latest modified bot baseline.

Changes:
- Trend lifecycle classification: EARLY / DEVELOPING / MATURE / EXTENDED / EXHAUSTING.

- Trend-leg re-entry budget: 2nd same-leg entry +4 score, 3rd +8 and requires fresh 15M BOS.
- XAU probation: +5 score and minimum positive 15M directional edge.
- MFE / MAE / realized R are tracked in live positions and persisted in the close journal.
- Existing fixed margin, max positions, anti-whipsaw, AI exits, sleep mode and setup families are retained.
