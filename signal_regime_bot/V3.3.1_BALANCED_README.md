## Balanced adaptive policy
Lifecycle threshold penalty:
- EARLY 0
- DEVELOPING 0
- MATURE +1
- EXTENDED +3
- EXHAUSTING +5

Same-leg penalty:
- first entry 0
- second entry +2
- third and later +4 maximum
- NO mandatory fresh 15M BOS hard gate

The policy helper is isolated in `balanced_policy.py` so it can be integrated into
the entry candidate threshold path without rewriting the current strategy core.
