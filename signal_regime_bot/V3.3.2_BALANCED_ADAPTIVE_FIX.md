# V3.3.2 Balanced Adaptive Fix

Fixes over-filtering introduced by V3.3.1.

- EXHAUSTING now requires a mature trend leg; a fresh high-extension impulse is no longer automatically treated as exhausted.
- Lifecycle threshold add-ons reduced: mature +1, extended +2, exhausting +4.
- Same-leg quality add-ons reduced: second +2, third+ +4.
- Removed the hard "third entry must wait for fresh 15M BOS" veto. Existing anti-whipsaw and re-entry reset logic remain active.
- XAU probation softened to +3 score and 15M edge >= +3, retaining symbol-specific protection without effectively disabling XAU.
- No changes to fixed margin, SL/TP, AI Exit, OKX sync, sleep/weekend controls, or trade journal.
