# DUALCORE V3.0 — Expert Multi-Mode Entry

## Objective

Rewrite the strategy core so the bot can find valid entries more often without relying on a single EMA cross. The performance objective is **WR ≥ 67% and PF > 1.20**, but these are targets—not guaranteed outcomes.

## Production architecture

```text
Closed market data
    ↓
4H Macro Conflict Filter
    ↓
1H Regime + Directional Bias
    ↓
15M Structure / BOS / SMC Zone Map
    ↓
5M Multi-Mode Execution
    ↓
Fee-aware Stop / Room / Actual-RR Gate
    ↓
Position Manager + TP1 / Runner / Safety Locks
```

## Active entry engines

1. `EMA_CROSS_5M`
   - Fresh EMA8/EMA13 cross.
   - Requires 15M context, ADX, directional DMI and anti-extension gates.
   - EMA cross is a timing trigger, not the sole reason for entry.

2. `SMC_ZONE_REJECTION`
   - Uses active 15M or 1H demand/supply from order blocks and fair-value gaps.
   - Requires an actual zone touch, rejection/micro-break/BOS, directional edge, DMI, RSI and extension quality.
   - 1H zones require 15M structural confirmation.

3. `BREAKOUT_RETEST`
   - Trades only the first fresh retest after a confirmed structure break.
   - Direct breakout is kept in code but disabled by default to reduce chase and fee-heavy false breaks.

4. `LIQUIDITY_SWEEP`
   - Requires a sweep and reclaim at mapped demand/supply.
   - Rejects weak closes and already-exhausted local directional scores.

5. `MOMENTUM_CONTINUATION`
   - Requires aligned 15M structure, a real 5M pullback and a fresh EMA recross with a previous-bar break.

## Optional engines retained in code

- `EMA_CROSS_15M`: supported but direct 15M execution is disabled by default. The 15M frame remains the setup/context layer while 5M is the precision execution layer.
- `STRUCTURE_PULLBACK`: retained but disabled by default because generic EMA20 pullbacks were less stable than SMC/retest entries during validation.
- `DIRECT_BREAKOUT`: retained but disabled by default.
- `RANGE_REVERSAL`: retained but disabled by default. Range/compression can still trade through sweep-at-zone logic.

## Important hard gates

- Strong opposite 15M cluster veto.
- Local long-vs-short directional edge.
- Trend-quality ADX and DMI gates for EMA/Pullback entries.
- SMC zone width, RSI, DMI and anti-exhaustion controls.
- Fresh breakout retest age: one bar.
- Active opposing supply/demand room.
- Minimum actual R:R after stop normalization.
- Fee-drag rejection using real round-trip fee assumptions and expected slippage.
- 0.75% minimum stop-distance floor, with ATR and fee-aware normalization.

## State and overtrade protection

- JSON tuple/list state restoration fixed, so duplicate signal keys survive restarts correctly.
- One position per symbol and maximum two concurrent positions remain unchanged.
- Full-SL cooldown: 90 minutes.
- After two same-side full SLs, that direction is locked until a fresh 15M BOS or the re-entry lock expires.
- Signal exits are armed only after TP1 to prevent repeated fee-heavy premature exits.

## Risk defaults retained

```text
Risk per accepted trade: 5% of balance
Maximum concurrent positions: 2
TP1: 1.20R, close 50%
TP2: setup-specific, normally 2.0R–2.4R
Minimum actual R:R: 1.35
Fee assumption: 0.10% per fill
Expected slippage: 0.05%
```

At 5% risk per trade, this remains aggressive. Paper/demo validation is required before full live risk.
