### 1B. Beat Rate Signal
```
EPS Beat Rate     Signal
────────────────────────────────────────────────
≥ 87.5% (7/8)    = Outstanding — high conviction ✅
75.0% (6/8)      = Strong ✅
62.5% (5/8)      = Average ⚠️
50.0% (4/8)      = Below avg ⚠️
< 50%            = Concerning ❌ — check management credibility

Note: EPS beat via buyback/cost cut ≠ quality beat
      Must verify with FCF and revenue beat together
```

## HARD RULES
```
❌ EPS beat must be verified beat ไม่ใช่แค่ non-GAAP
❌ ห้าม present EPS beat ถ้า revenue miss (partial beat only)
❌ ห้ามใช้ non-GAAP อย่างเดียว ต้องมี GAAP comparison
❌ Revision data ต้องมี 3-month comparison ไม่ใช่แค่ current
❌ DATA [U] = 0 คะแนน (Governance Rule #5)
❌ PEAD signal ต้องมี earnings date จริง [V] ไม่ใช่ estimate
```
